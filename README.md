Escopo do projeto.

O Driftboard foi desenvolvido como um projeto acadêmico com o foco exclusivo em desenvolvimento frontend,
utilizando HTML, CSS, JavaScript. 

O objetivo foi construir a interface e as funcionalidade de um sistema Kanban, permitindo a organização e o 
acompanhamento de tarefas.
As telas de login e solivitação de acesso forem desenvolvido apenas para demonstração visual, não sendo 
implementadod os mecanismos reais de autenticação ou cadastro de usuário.

O projeto não possui backend nem integração com banco de dados, pois esses recursos não faziam parte dos 
requisitos academicos. As tarefas são armazenadas localmente no navegador por meio do localStorage.
